# Q2 文献—模型对应表

## 1. 目的与证据边界

本文件把 Q2 的四篇专用文献映射到四层计算链：

`visual stimulus → LGN/thalamus → cortical population → source → scalp EEG`。

文献中的实验动物、测量模态和参数不等同于本题的人类三通道 EEG 条件。所有结论按以下证据等级标记：

| 等级 | 含义 |
|---|---|
| A | 本题数据或人类 EEG/神经数据直接支持；当前四篇论文没有提供可归入 A 的 Q2 参数。 |
| B | 动物视觉系统实验证据，可支持机制方向，不能把数值直接移植为人类参数。 |
| C | 经典神经动力学/计算建模框架，结构合理但不是本题的直接实验事实。 |
| D | 为三通道条件下可辨识性、数值稳定或模型比较而作的简化假设。 |

页码均指项目中提取文本对应的 PDF 页码，而不是期刊 HTML 页码。

## 4. 不能由当前四篇论文直接确定的内容

以下项目必须在模型和后续报告中标为“未由所给文献确定”，不能伪装成文献参数：

1. 人类 LGN→视觉皮层的传导延迟、LGN 时间常数和皮层 E/I 时间常数。
2. 本题 F3/Fz/F4 的真实个体 lead field、源位置和参考电极影响。
3. Wilson–Cowan 在本视觉任务中的唯一耦合矩阵、sigmoid 斜率和基线。
4. 三角形 Left/Right 是否对应具体视野位置或是否必然产生稳定差异。
5. 将 Lien–Scanziani 的 32–36% 丘脑兴奋贡献直接作为人类 EEG 的固定比例。
6. 将 Horrocks 的 FA 因子、trajectory tangling 或 3–5 Hz 现象直接当作 Q2 的生理参数。

因此，Q2 的“先进性”来自结构化的 mechanistic model + observation model + 可辨识性约束，而不是声称四篇论文已经给出了本题的完整参数集。

## 5. 建模决策

- 主模型候选为 A（经验线性）、B（LGN + 线性皮层）和 C（LGN + Wilson–Cowan E/I）。
- 三个模型共享输入编码、通道顺序和低维 source 观测接口；Task1/Task2 只允许有限的增益、基线或耦合调制。
- 先用完整 ERP waveform 评估，随后用复杂度惩罚和留出记录检验是否需要 B/C；如果 B 与 C 的泛化相当，优先保留 B。
- 模型输出只能解释 Q1 的宏观波形，不进行未经 MRI/高密度 EEG 支持的精确 source localization。
